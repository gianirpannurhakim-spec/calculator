Ringkasan Eksekutif

Gambaran singkat hasil pengerjaan

Project ini menghasilkan sebuah website kalkulator statis yang berjalan sepenuhnya di sisi klien. Aplikasi terdiri atas tiga berkas sumber terpisah — struktur, tampilan, dan logika — tanpa framework, tanpa dependensi eksternal, dan tanpa proses build. Seluruh perhitungan ditangani oleh parser aritmetika buatan sendiri sehingga tidak menggunakan eval().

Hasil utama

  • Operasi aritmetika dasar (+ − × ÷), persen, desimal, dan pembalikan tanda berfungsi sesuai harapan.
  • Pratinjau hasil muncul langsung saat mengetik, sehingga pengguna dapat memeriksa ekspresi sebelum menekan =.
  • Format angka mengikuti konvensi Indonesia: titik sebagai pemisah ribuan dan koma sebagai desimal.
  • Pembagian dengan nol ditangani sebagai kesalahan terkendali, bukan crash atau Infinity.
  • Tampilan responsif, ramah keyboard, dan menghormati preferensi reduced motion.

Latar Belakang dan Tujuan

Mengapa project ini dibuat dan apa yang ingin dicapai

Latar belakang

Kalkulator merupakan salah satu aplikasi paling sederhana yang sekaligus menguji banyak konsep dasar pengembangan web: pengelolaan state, penanganan input, validasi, pemformatan angka, hingga aksesibilitas. Membangunnya dari nol tanpa pustaka pihak ketiga memberi pemahaman menyeluruh tentang bagaimana antarmuka, logika, dan penyajian data saling terhubung di browser.

Selain itu, kalkulator berbasis web dapat diakses langsung dari perangkat apa pun tanpa instalasi, sehingga cocok sebagai contoh aplikasi ringan yang siap dipakai.

Tujuan

  1. Membangun website kalkulator sederhana yang berfungsi penuh di browser modern.
  2. Memisahkan struktur (index.html), tampilan (style.css), dan logika (script.js) secara jelas.
  3. Menjamin akurasi perhitungan melalui parser dengan prioritas operator yang benar.
  4. Menghindari eval() agar evaluasi ekspresi aman dari eksekusi kode berbahaya.
  5. Menguji seluruh fungsi utama secara terukur dan mendokumentasikan hasilnya.

Batasan

  • Hanya operasi aritmetika dasar, persen, dan tanda kurung tidak disertakan.
  • Satu ekspresi per perhitungan (tanpa riwayat permanen).
  • Tanpa fungsi ilmiah (akar, pangkat, trigonometri).
  • Berjalan sepenuhnya di klien; tidak ada server atau basis data.
  • Riwayat hanya menyimpan operasi terakhir di memori.
  • Target browser: Chrome, Edge, Firefox, dan Safari versi terbaru.

Arsitektur dan Cara Kerja

Alur data dari input pengguna hingga tampilan hasil

Logika aplikasi dibungkus dalam Immediately Invoked Function Expression (IIFE) agar tidak mencemari global scope. Seluruh data perhitungan disimpan dalam satu objek state yang menjadi sumber kebenaran tunggal.

5.1 Manajemen state

const state = {
  expression: '',      // ekspresi mentah, mis. "12+5"
  history: '',         // teks riwayat, mis. "12+5 ="
  preview: null,       // hasil sementara (null = belum ada)
  error: '',           // pesan kesalahan aktif
  justEvaluated: false // true tepat setelah tombol "="
};

Penanda justEvaluated membedakan dua perilaku setelah hasil keluar: mengetik angka memulai perhitungan baru, sedangkan menekan operator melanjutkan perhitungan dari hasil sebelumnya — misalnya 2+3= lalu ×2= menghasilkan 10.

5.2 Parser aritmetika tanpa eval

Ekspresi dipecah menjadi token (angka, operator, persen) lalu diurai dengan recursive descent yang menerapkan prioritas: faktor → suku → ekspresi. Dengan urutan ini, 2+3×4 otomatis dihitung sebagai 14. Karena tidak ada eval(), teks yang diketik pengguna tidak pernah dieksekusi sebagai kode.

  • Faktor — angka, tanda unary +/−, serta persen postfix (50%).
  • Suku — perkalian dan pembagian, dengan pemeriksaan pembagi nol.
  • Ekspresi — penjumlahan dan pengurangan.

Parser juga memvalidasi sisa token dan memastikan hasil akhir berupa bilangan hingga, sehingga input seperti 5÷0 menghasilkan pesan “Tidak bisa dibagi nol” alih-alih nilai tak hingga.

5.3 Akurasi dan pemformatan

JavaScript memakai bilangan floating point yang dapat menimbulkan sisa pecahan (misalnya 0,1+0,2). Aplikasi meredam hal ini dengan membulatkan hasil ke 12 digit signifikan sebelum ditampilkan, lalu memformatnya menggunakan Intl.NumberFormat('id-ID'). Hasilnya, 0,1+0,2 tampil sebagai 0,3 dan 123456789 menjadi 123.456.789.

5.4 Lapisan tampilan

Fungsi refreshPreview() menghitung hasil sementara dan mengabaikan ekspresi yang belum lengkap (berakhir dengan operator). Fungsi render() kemudian menuliskan ekspresi, riwayat, dan pratinjau ke DOM, sekaligus mengecilkan ukuran font bila ekspresi melebihi 12 karakter agar tidak meluap dari layar.

Lampiran: Potongan Kode Inti

Cuplikan dari script.js

A.1 Hierarki parser

Setiap tingkat hanya menangani satu kelompok operator, sehingga prioritas dijalankan secara alami oleh struktur pemanggilan fungsi. 

// faktor: angka, tanda unary, dan persen postfix
function parseFactor() {
  let sign = 1;
  while (peek() && (peek().type === '+' || peek().type === '-')) {
    if (peek().type === '-') sign *= -1;
    position += 1;
  }
  // ... membaca angka, menerapkan '%', lalu mengembalikan sign * value
}

// suku: perkalian dan pembagian
function parseTerm() {
  let value = parseFactor();
  while (peek() && (peek().type === '*' || peek().type === '/')) {
    const operator = tokens[position++].type;
    const right = parseFactor();
    if (operator === '*') value *= right;
    else {
      if (right === 0) throw new Error('div0');
      value /= right;
    }
  }
  return value;
}

// ekspresi: penjumlahan dan pengurangan
function parseExpression() {
  let value = parseTerm();
  while (peek() && (peek().type === '+' || peek().type === '-')) {
    const operator = tokens[position++].type;
    const right = parseTerm();
    value = operator === '+' ? value + right : value - right;
  }
  return value;
}

A.2 Render tampilan

function render() {
  const shownExpression = displayExpression(state.expression) || '0';

  expressionEl.textContent = shownExpression;
  expressionEl.classList.toggle('is-small', shownExpression.length > 12);
  historyEl.textContent = state.history;

  if (state.error) {
    resultEl.textContent = state.error;
    resultEl.classList.add('error');
    return;
  }

  resultEl.classList.remove('error');
  resultEl.textContent =
    state.preview === null ? '' : '= ' + formatValue(state.preview);
}

A.3 Pratinjau hasil

function refreshPreview() {
  state.preview = null;
  state.error = '';

  const expression = state.expression;
  if (!expression) return;
  // angka tunggal tidak perlu pratinjau
  if (/^-?\d+(?:\.\d*)?$/.test(expression)) return;
  // ekspresi yang belum selesai tidak dievaluasi
  if (/[+\-*/]$/.test(expression)) return;

  try {
    state.preview = evaluate(expression);
  } catch (error) {
    if (error.message === 'div0') state.error = 'Tidak bisa dibagi nol';
  }
}
